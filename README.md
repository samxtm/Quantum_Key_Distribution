# An Explainable and Federated Machine Learning Framework for Secure Quantum Key Distribution under Adversarial Conditions

##  Project Overview

This project presents a **Machine Learning-enhanced Quantum Key Distribution (QKD) framework** for secure communication networks. It integrates:

-  Quantum Key Distribution (BB84 Simulation)
-  Machine Learning-based Attack Detection
-  Explainable AI (SHAP)
-  Federated Learning Simulation
-  Adversarial Robustness Testing

The goal is to build a **secure, scalable, and interpretable quantum communication system** for next-generation cybersecurity applications.

---

##  Key Features

### Quantum Layer
- BB84 Protocol Simulation
- Quantum Bit Error Rate (QBER) Calculation
- Key Sifting Process

###  Machine Learning Layer
- Random Forest Classifier
- Attack vs Normal Detection
- Model Comparison Support

###  Federated Learning Layer
- Multi-client local training simulation
- Aggregated prediction mechanism
- Privacy-preserving distributed learning

###  Explainable AI Layer
- SHAP Summary Plot
- SHAP Waterfall Plot
- SHAP Force Plot
- Feature Importance Analysis

###  Security Layer
- Adversarial Noise Injection
- Robustness Evaluation
